# 🧠 Brain Tumor Detection using CNN (MRI Images)

This project uses a Convolutional Neural Network (CNN) to classify brain
MRI images as tumor or no tumor.

## 🚀 Features

-   CNN model using Keras
-   MRI image classification
-   Gradio UI (optional)
-   Pre-trained model included

## 📁 Project Structure

-   Brain_Tumor_detection.ipynb
-   app.py
-   model.pkl
-   No22.jpg
-   Y257.jpg
-   requirements.txt

## ⚙️ Installation

pip install -r requirements.txt

## ▶️ Usage

Run the notebook to train and test the model.

## 📊 Dataset

-   Yes (Tumor)
-   No (No Tumor)
-   Images resized to 128x128

## ⚠️ Disclaimer

Not for medical use.
